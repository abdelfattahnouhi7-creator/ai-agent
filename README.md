🤖 My First AI Agent + IMPACT Bricks

Agent كيجرب الكود، كيعاود، وكيصلح راسو بوحدو باستعمال Google Gemini.
و IMPACT كيحفظ الكود الناجح كـ لبنات، وكيعاود يستعملهم.

شنو كيدير الـ Agent؟
1. كيجرب الكود بـ 3 Tests
2. إلا فشل، كيصيفط المشكل لـ Gemini
3. Gemini كيصلح الكود وكيعاود يجرب
4. كيبقى يعاود حتى ينجح 3/3

شنو هي مكتبة اللبنات - bricks/ ؟
أي كود نجح 3/3، كيتحفظ كـ لبنة، باش نعاودو نستعملوه بلا ما نعاودو نبنيوه.

| اللبنة | شنو كتدير | الحالة |
| :--- | :--- | :--- |
| brick-001 | average - كيحسب المعدل بأمان، كيرفض الليستة الخاوية بـ ValueError | ✅ verified 3/3 |
| brick-002 | safe_divide - قسمة آمنة، كترفض القسمة على صفر بـ ValueError | ✅ verified 3/3 |

مثال - IMPACT كيركب جوج لبنات:
```python
m = average([10, 20, 30])  # 20.0 - من brick-001
result = safe_divide(m, 2)  # 10.0 - من brick-002
